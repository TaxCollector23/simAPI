The `simapi` CLI validates robot recordings through the same hosted engine used by the playground. It works without an account, login, API key, or local server on the public service.

## Install

Requires Node.js 18 or later.

```bash
npm install -g simapi-cli
```

Run `simapi` for the common commands or `simapi --help` for the full list.

## Quick start

```bash
simapi
simapi init
simapi inspect episode.csv
simapi validate episode.csv
```

`simapi init` creates a local `simapi.json` settings file and does not overwrite an existing one. Use CSV or JSON recordings directly, or import ROS recordings as JSON first:

```bash
simapi import capture.mcap --list-topics
simapi import capture.mcap --topic /joint_states --output run.json
simapi validate run.json
```

`inspect`, `profile import`, `compare`, and `repair` run locally. Validation is sent to `https://simapilander.vercel.app/api` by default. The public hosted service requires no login or key.

## Profiles

Create a profile from URDF joint limits, then use it when importing or validating a run:

```bash
simapi profile import arm.urdf --name arm --output arm-profile.json
simapi import capture.mcap --topic /joint_states --profile arm --output run.json
simapi validate run.json --profile ./arm-profile.json
```

You can also use the built-in FTC/FRC profile with `--profile ftc`. Pass `--profile` a saved profile name or a JSON profile path.

## CI

Use the report's **Copy CI command** action to replay the same run and profile. `--exact-profile` applies the downloaded profile settings without merging local project or recording settings.

```bash
simapi validate ./simapi-run.json --profile ./simapi-profile.json --exact-profile --no-ai --format github --report ./simapi-report.json --fail-on failed
```

Choose `--fail-on failed` to fail only on errors, or `--fail-on warning` to fail on warnings and errors. The JSON report is written even when the chosen threshold is reached. Exit code `0` means validation completed below the threshold, `1` means the threshold was reached, and `2` means the CLI could not complete validation or save the report.

`--format github` writes escaped workflow annotations to stderr. With `--json`, stdout contains only the JSON report; diagnostics remain on stderr.

## Other commands

```bash
simapi profile list
simapi compare baseline.json current.json --json --fail-on regression
simapi repair run.json
simapi watch run.json --profile arm
```

Repair previews run locally. `--apply` writes a separate repaired file and never overwrites the input.

## Configuration

Set `SIMAPI_BASE_URL` to validate against another service. Set `SIMAPI_API_KEY` only when that service requires a key. The public hosted service needs neither. For private deployments, a key can also be saved through `simapi api-key set --stdin`; the CLI masks saved keys when showing status.

```bash
export SIMAPI_BASE_URL="http://localhost:8000/api"
```
