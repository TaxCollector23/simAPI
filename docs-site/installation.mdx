Install a SimAPI client to validate recordings with a hosted or self-hosted
service. The public hosted service requires no account or API key. Install the
server itself only when you need a local or private deployment.

## Python SDK

```bash
pip install simapi
```

The Python SDK calls the public hosted service without an API key. Set
`SIMAPI_BASE_URL` for another endpoint, and `SIMAPI_API_KEY` only if that
endpoint requires authentication.

## Node SDK and CLI

The Node package includes both the SDK and the hosted `simapi` CLI. Use the
package as an application dependency:

```bash
npm install simapi-cli
```

For the terminal command, use Node.js 18 or later:

```bash
npm install -g simapi-cli
```

The public hosted CLI needs no account, login, or API key. For a private
service, set `SIMAPI_BASE_URL` and add `SIMAPI_API_KEY` only if authentication
is enabled there.

## Run the server locally

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/TaxCollector23/simAPI.git
    cd simAPI
    python -m venv .venv && source .venv/bin/activate
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Configure">
    ```bash
    cp .env.example .env
    # Optional: set SIMAPI_OPENROUTER_API_KEY to enable the AI layer
    ```
  </Step>
  <Step title="Launch">
    ```bash
    python launch.py   # API on :8000, docs at /docs, dashboard opens
    ```
  </Step>
</Steps>

## Run with Docker

<CodeGroup>

```bash Docker
docker build -t simapi:latest .
docker run -p 8000:8000 --env-file .env simapi:latest
```

```bash Docker Compose
docker compose up --build
```

</CodeGroup>

<Note>
  The image is multi-stage, runs as a non-root user, and ships a health check
  hitting `/v1/health`. See [Enterprise](/enterprise) for private-deployment
  guidance.
</Note>

## Verify

curl http://localhost:8000/v1/health
